# 全 CG 与回想存档生成器使用说明

[下载 Windows 生成器](https://github.com/darkAuska/pix-cg-save-generator/releases/latest/download/pix-cg-save-generator-windows.zip)

双击 `全CG与回想存档生成器.exe` 即可在 Windows 上运行。EXE 内含所需运行时。工具可生成全 CG、全回想，或两者一起解锁的 ZIP。安装存档需要手动复制 ZIP 内的文件。

## 支持的引擎和游戏版本

**当前适配 PIX（PIX GAME STUDIO）引擎的下列两套 Windows 游戏版本。** 支持范围以表中的游戏版本和汉化补丁组合为准。

| 游戏和汉化补丁 | 安装目录中的程序 | 完整 CG 图鉴 | 全部回想 |
|---|---|---:|---:|
| Eclipse HD Remaster 1.00 · gemini-2.5-pro 汉化 | `eclipsehd.exe` | 142 组、414 张 | 78 段 |
| けがれた英雄 HD 1.00 · 影之君主 DeepSeek-R1-0528 汉化 | `hideohd.exe` | 214 组、422 张 | 71 段 |

**其他 PIX 游戏、表中两作的日文原版和其他汉化补丁，以及其他引擎的游戏，目前均不支持。** 生成器会核对游戏 EXE 和脚本的文件指纹。即使同样使用 PIX 引擎，或游戏也显示版本号 1.00，仍需匹配表中已适配的版本才能生成。

## 生成存档

1. 打开生成器，在「游戏安装目录」旁点「浏览…」，选择**包含游戏 EXE 的文件夹**。识别成功后，窗口会显示游戏版本和图鉴、回想数量。
2. 在「生成方式」选择所需模式。
   - **自用**用于补齐现有档。程序会尝试自动找到 `pix.pixglobal`，也可以在「源全局存档」手选同版本的原档或备份。生成结果保留源档已有的全局进度。
   - **分享**用于制作可发给别人的存档。程序以空白全局档为基础，只写入你选择的解锁项目。此模式可以直接生成，无需提供源档。
3. 在「解锁范围」选择 **全 CG 与全回想**、**全 CG** 或 **全回想**。
4. 选好「导出位置」，点「生成 ZIP」。完成后点「打开导出位置」。ZIP 内有 `pix.pixglobal` 和 `使用说明.txt`。再次生成时，同名 ZIP 会加序号。

## 安装和恢复

1. 完全退出游戏。在 Windows 文件资源管理器的地址栏输入对应目录。
   - **Eclipse HD** · `%APPDATA%\clockup\eclipsehd`
   - **けがれた英雄 HD** · `%APPDATA%\clockup\hideohd`
2. 如果目录还没创建，先启动游戏一次，再退出。把目录里现有的 `pix.pixglobal` 复制到别处备份。装入分享档后，原有的其他全局收集进度可用这份备份恢复。
3. 解压生成的 ZIP，把里面的 `pix.pixglobal` 复制到该目录。若已有同名文件，确认备份已保存后再替换。普通存档槽在 `SaveData` 文件夹里。
4. 重开游戏，进入 **EXTRA → GALLERY** 检查 CG，点开几组查看组内变体。进入 **EXTRA → SCENE** 检查回想，抽点几段确认能进入对应剧情。
5. 若要恢复原进度，退出游戏，把备份的 `pix.pixglobal` 换回原目录。

## 分发和反馈

- **测试生成器**时，把 EXE 和本说明一起发给测试者。测试者需要装有上表中的任一版本。
- **测试生成好的档**时，发送生成的分享 ZIP。接收者按 ZIP 内的说明安装即可。
- **反馈问题**时，请附上游戏版本、汉化补丁名、选的生成方式和解锁范围，以及报错截图。若游戏读档后有缺项，可注明是在 `GALLERY` 还是 `SCENE`、第几页第几格，以及点击后的表现。

| 遇到的情况 | 检查方法 |
|---|---|
| 找不到游戏或汉化脚本 | 确认选的是含 `eclipsehd.exe` 或 `hideohd.exe` 的游戏根目录，并且对应汉化补丁已完整应用。 |
| 游戏或脚本与已核对的版本不符 | 对照上面的版本表。即使游戏显示同样的 1.00，换了汉化补丁也可能导致识别失败。 |
| 自用模式找不到源档 | 指定对应游戏的 `pix.pixglobal` 或备份。首次运行的游戏可先启动并退出一次，再检查存档目录。 |
| 生成成功，进入游戏仍有缺项 | 确认替换文件时游戏已完全退出，核对复制目标和生成时选择的解锁范围。记录缺失的页码和格子，便于复现。 |

## 技术和源码

两作的全局档采用 TLZ 压缩。生成器从 `extra.txt` 读取图鉴清单，把图片路径转换为存档使用的文件名。Eclipse 的 414 张图鉴图片对应 398 个不同的文件名记录，所以生成器显示的解锁记录数可能小于图鉴图片数。

两作的回想菜单都按存档编号判定解锁，并在点击后从已加载的脚本查找播放入口。《けがれた英雄 HD》的分享档填写了回想位置字段，隔离复验中把这些字段全部置零后，缩略图仍可显示，抽测的第一段也进入了对应剧情。

`savegen.py` 负责全局档读写和校验，`generator.py` 提供窗口，`profiles.json` 记录支持版本的文件指纹和条目信息。源码版在源码目录运行 `python generator.py`，需要 Python 3.10 或更新版本及 Tkinter。
